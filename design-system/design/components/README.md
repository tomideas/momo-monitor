# 组件扩展（Components）

本目录只收录项目中真实存在、重复使用或已经确认即将使用的组件，不预建通用组件百科。

先在 `../design-system.json` 的 components 数组添加组件资料，页面会自动显示可编辑卡片。复杂组件再增加真实视觉样本；卡片不等于组件已实现。AI 先读取 `../AI.md`。

组件适合进入目录的条件：

- 已在两个或以上位置重复使用；
- 多人或 AI 修改时容易出现结构、尺寸或状态漂移；
- 已经有明确的真实源码位置（Source Path）；
- 允许变体和交互状态已经能够说明。

每个组件至少记录：

1. 名称、用途与真实源码路径；
2. 属性或输入（Props / Inputs）；
3. 允许变体（Variants）；
4. hover、focus、active、disabled、error、loading 等适用状态；
5. 可见样本（Visual Specimen）；
6. 正确与错误用法（Do / Don't）；
7. 仍待确认的差异。

项目需要代码级组件目录时，可以逐步增加真实的 `.jsx`／`.tsx`、类型定义、示例或组件说明；不要复制一份与产品源码脱离的实现。
